# Investigation Checklist

Use this checklist before returning an investigation.

## Evidence

- [ ] The scope, objective, and any limits are explicit.
- [ ] Local evidence was checked before remote sources unless the request required remote evidence.
- [ ] Each material claim has a precise, relevant citation.
- [ ] Repeated evidence and claims are removed.

## Conclusions

- [ ] Facts, tentative claims, conflicts, and unknowns are distinct.
- [ ] Each tentative claim states why evidence is incomplete.
- [ ] Each conflict shows the evidence needed to resolve it.
- [ ] The summary contains the main facts and unresolved unknowns without remediation or speculation.
