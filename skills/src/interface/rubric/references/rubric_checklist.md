# Rubric Checklist

Use this checklist to assess rubric conformance and quality.

## Identity

- [ ] The title starts with `RUBRIC-<slug>`.
- [ ] The slug is lowercase kebab-case and identifies the rubric.

## Structure

- [ ] The rubric contains a `Criteria` section.
- [ ] Criteria are grouped only by applicable domains.
- [ ] Each criterion has a stable, unique `<PREFIX>-<three-digit sequence>` ID.
- [ ] Each prefix uses numbering that starts at `001`.

## Quality

- [ ] Each criterion states one observable quality condition.
- [ ] Each criterion is clear enough to evaluate without guessing.
- [ ] Criteria are concise and do not duplicate one another.
- [ ] The selected domains are relevant to the rubric purpose.

## Separation

- [ ] The rubric contains no evaluation records, result values, evidence, impact, confidence, follow-up work, summaries, or completion state.
- [ ] The rubric does not prescribe how downstream skills apply criteria or record results.
