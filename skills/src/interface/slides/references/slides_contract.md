# Slide Deck Contract

## Title Slide

- Start with one `#` title.
- Add one subtitle only when useful.

## Body Slides

- Separate each slide with `---`.
- Start each body slide with one `##` heading.
- Add one `###` subheading below the heading.
- Make each heading and subheading state the point, not only its topic.
- Use no more than six bullets per slide.
- Use no more than six key words per bullet.
- Do not nest bullets.
- Add source links only when needed.
