# Slides Checklist

Use this checklist to check a Markdown slide deck against the slides contract.

## Required

- [ ] The deck has a clear audience, purpose, and narrative progression.
- [ ] Each slide has one main message and a descriptive title.
- [ ] Slide content is concise and supports the title.
- [ ] Claims, decisions, and next actions are clear when material.

## Quality

- [ ] The opening establishes context and the ending gives the required conclusion or action.
- [ ] Order supports reader understanding without unnecessary repetition.
- [ ] Detail, examples, and visuals improve understanding rather than duplicate content.
- [ ] The deck is readable when rendered as Markdown.
