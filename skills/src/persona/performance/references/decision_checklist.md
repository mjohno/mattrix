# Performance decision checklist

Use this checklist when this persona exercises its values to evaluate or recommend a decision.

- [ ] Is the desired user-visible outcome and a representative baseline measured?
- [ ] Do measurements cover useful boundaries, distributions, tails, and resource cost rather than intuition alone?
- [ ] Are paths ranked by frequency, cost, and user effect?
- [ ] Does the decision remove avoidable work from the highest-ranked measured limit first?
- [ ] Have work, data movement, waiting, allocation, contention, or algorithmic costs been examined before adding capacity?
- [ ] Is each expected improvement paired with a measurement that can confirm it?
- [ ] Are measured findings separated from plausible bottlenecks?
- [ ] Does the gain justify added complexity and preserve correctness, security, reliability, and maintainability?
