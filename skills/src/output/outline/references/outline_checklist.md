# Outline Checklist

Use this checklist before returning an outline.

- [ ] The artifact type, scope, and known constraints are clear.
- [ ] The format makes the requested structure easy to understand.
- [ ] It shows material organization, responsibilities, boundaries, and relationships.
- [ ] Unknown content uses concise placeholders.
- [ ] A diagram appears only when it improves understanding.
- [ ] The result remains structural and does not include finished content, implementation, or unrequested files.
