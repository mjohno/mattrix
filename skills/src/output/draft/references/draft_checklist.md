# Draft Checklist

Use this checklist before returning a draft.

- [ ] The structure follows the requested format or supplied interface contract.
- [ ] Content comes only from supplied context and keeps source qualification where available.
- [ ] Material ambiguities, assumptions, risks, missing inputs, unresolved decisions, and incomplete sections are explicit.
- [ ] Confirmed facts are separate from ideas, proposals, and unknowns.
- [ ] Unsupported sections remain marked rather than completed by guesswork.
- [ ] The result is a reviewable first pass, not investigation, verification, decision-making, or implementation.
