# Handoff Checklist

Use this checklist before returning a handoff.

- [ ] The document has a stable `HANDOFF-<slug>` ID, title, Source, and Purpose.
- [ ] It includes Next-Session Focus, Goal, Current State, Completed, Next, Decisions, Open Questions, References, and Suggested Skills.
- [ ] It contains only information needed to continue work and links to existing artifacts instead of copying them.
- [ ] Secrets and personal data are excluded.
- [ ] The file name is unique when written to a change path.
- [ ] The handoff is returned in chat only when no change path is supplied.
