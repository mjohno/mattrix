# Stagger Step Initialization Checklist

Use this checklist before returning an initialization result.

## Preconditions

- [ ] The goal is supplied or approved after the `goal` skill proposes it.
- [ ] References and lessons are owner-supplied and kept in supplied order.
- [ ] Inferred STEP and change paths received explicit owner approval.
- [ ] The STEP file did not already exist.

## Result

- [ ] Required parent directories, packet history, and commit-mode requirements were validated.
- [ ] Initialization used the requested settings and passed each reference and lesson unchanged.
- [ ] The initial owner gate was rendered but not approved or advanced.
- [ ] The response includes the created state path, settings, and a shell-escaped continuation command.
