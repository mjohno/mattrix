# Walkthrough Checklist

Use this checklist while guiding a walkthrough.

## Guidance

- [ ] The current scope is clear enough to orient; unclear scope was refined with the user.
- [ ] Each explanation covers one connected area and uses available evidence or examples.
- [ ] Deferred, skipped, active, and added areas remain visible in prompt-only context.
- [ ] Scope changes are explicitly reported.

## Boundaries

- [ ] The user controls depth, order, tangents, and stopping.
- [ ] The walkthrough did not impose a fixed curriculum or claim mastery.
- [ ] Files were created, modified, or annotated only on explicit user direction.
- [ ] The walkthrough continues until the user stops or is satisfied.
