# Mattrix KB

`kb/` implements Matt's Knowledge Format (MKF) from the passive contract at [`../skills/src/interface/knowledge-base/`](../skills/src/interface/knowledge-base/).

- `src/` is reserved for KB implementation code and consumes the skills-owned contract.
- `docs/` contains KB implementation documentation.

The KB does not define the MKF contract and does not depend on individual agent products.
