# Postmortem culture checklist

- [ ] Write a postmortem for a significant incident or near miss.
- [ ] Use a blameless account of facts, decisions, and system conditions.
- [ ] State the user effect, duration, detection method, and timeline.
- [ ] Identify contributing factors instead of assigning personal fault.
- [ ] Define specific, owned, and tracked follow-up actions.
- [ ] Share the postmortem with teams that can learn from it.
- [ ] Review action completion and recurring failure patterns.
- [ ] Improve the process from feedback on each postmortem.
