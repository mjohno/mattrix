# Incident management checklist

- [ ] Declare an incident when coordination is required to limit user harm.
- [ ] Establish one recognized command post.
- [ ] Assign incident command, operations, planning, and communication roles.
- [ ] Keep technical investigation focused and separate from coordination work.
- [ ] Maintain a live incident state document with facts, decisions, and next actions.
- [ ] Communicate scope, status, and expected updates to stakeholders.
- [ ] Prevent uncoordinated changes and duplicate work.
- [ ] Give each handoff a clear current state, owner, and next action.
