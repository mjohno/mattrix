# Software engineering in SRE checklist

- [ ] Select problems where software can remove a repeated operational limit.
- [ ] Define users, required inputs, outputs, and service boundaries.
- [ ] Model dependencies, performance data, and workload priorities.
- [ ] Prefer intent-based systems over repeated manual capacity decisions.
- [ ] Use approximations only when their limits are understood.
- [ ] Design the tool for the right scope and its actual users.
- [ ] Set adoption expectations and provide user support.
- [ ] Reserve staffing and time for engineering work in the SRE team.
