# Outage tracking checklist

- [ ] Record each outage in one shared tracking system.
- [ ] Capture start, end, user effect, service, and severity.
- [ ] Link the incident record and postmortem when they exist.
- [ ] Tag the outage by cause, trigger, and affected service area.
- [ ] Aggregate related events without losing useful detail.
- [ ] Report outage trends in a form that decision makers can use.
- [ ] Use the data to select reliability work and measure improvement.
- [ ] Review the taxonomy and data quality as services change.
